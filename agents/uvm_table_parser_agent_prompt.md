## Goal

Implement a parser for `uvm_table_print` text output.

The tool should support this high-level flow:

```text
uvm_table_print txt
  -> parse parameter name/value pairs
  -> apply optional name mapping
  -> generate Python output file
```

Generated Python output should contain a function like:

```python
def para_get(parse):
    parse.<rm_para_name> = <para_value>
```

The UVM printed parameter name may differ from the final RM parameter name, so the tool must support a configurable mapping table.

## Required behavior

The first version should support:

```text
1. Read input txt file.
2. Parse parameter name/value rows from uvm_table_print-style output.
3. Ignore table borders, separators, empty lines, and unsupported lines.
4. Convert simple values:
   - decimal integer
   - hex integer such as 0x10
   - binary integer such as 0b1010
   - signed integer
   - simple string
5. Apply configurable mapping:
   uvm_name -> rm_name
6. Allow unmapped behavior to be configured:
   - keep original name
   - ignore unmapped
7. Generate a Python .py file containing:
   def para_get(parse):
       parse.<name> = <value>
8. Keep Python 3.6 compatibility.
9. Add pytest tests.
10. Add a small usage document.
```

## Suggested CLI

The utility should support a command line like:

```powershell
python utils/parse_uvm_table_print.py `
  --input tests/fixtures/uvm_table_print/demo_table.txt `
  --mapping schema_defs/uvm_table/demo_mapping.py `
  --output generated_para.py
```

If mapping is omitted, the tool may keep original names by default.

## Mapping format

Use a simple Python dict for the first version.

Example:

```python
PARAM_NAME_MAP = {
    "FreqDomainPosition": "freq_domain_position",
    "FreqDomainShift": "freq_domain_shift",
    "CSRS": "c_srs",
    "BSRS": "b_srs",
}
```

Optional settings may include:

```python
KEEP_UNMAPPED = True
```

## Output style

Generated file should be deterministic.

Example output:

```python
# Auto-generated by utils/parse_uvm_table_print.py

def para_get(parse):
    parse.freq_domain_position = 10
    parse.freq_domain_shift = 2
    parse.c_srs = 18
```

Use `repr(value)` when rendering Python literals.

## Error handling

Errors should be clear.

Examples:

```text
input file not found
mapping file not found
invalid mapping file: PARAM_NAME_MAP missing
cannot parse output path
duplicate RM parameter name
```

Do not silently generate partial output if there is a serious parsing error.
